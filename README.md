# EDUPLACE — School Placement Portal

EDUPLACE is a frontend demonstration of a school placement portal designed to provide students with a simple interface for checking their school placement information.

The project allows users to enter an examination index number, select an examination year and view a demonstration placement result.

## Project Overview

The portal features a modern interface with a navigation menu, welcome section, placement form, about section and footer.

It was developed as a practical exercise in HTML, CSS and JavaScript.

## Features

- **Responsive Navigation:** Provides links to the main sections of the website.
- **Hero Section:** Introduces the placement portal.
- **Placement Form:** Accepts an examination index number and examination year.
- **Basic Form Validation:** Checks that the index number is not empty.
- **Interactive Result Display:** Displays the submitted examination details.
- **Responsive Design:** Uses CSS media queries to adapt the layout to smaller screens.

## Technologies Used

Open `structure.html` in your web browser.

## How It Works

1. Open the placement portal.
2. Navigate to the Check Placement section.
3. Enter an examination index number.
4. Select an examination year.
5. Click the Check Placement button.
6. View the demonstration result displayed below the form.

## Current Limitations

This project is currently a frontend demonstration.

- It does not connect to an official school placement database.
- No actual placement records are retrieved.
- Results are generated from the information entered by the user.
- There is no backend or database integration.
